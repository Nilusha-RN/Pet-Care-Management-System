# 🐾 Pet Care Management System

A console-based Pet Care Management System developed using Java and Object-Oriented Programming principles.

## Features

- Pet management
- Dog, Cat and Bird inheritance
- Pet search
- Owner management
- Appointment management
- Medical record management
- Animal sound polymorphism
- Reports and statistics
- Exception handling
- Menu-driven console interface

## OOP Concepts

- Encapsulation
- Inheritance
- Polymorphism
- Method Overriding
- Constructors
- Classes and Objects
- Object Relationships
- ArrayList
- Exception Handling

## Technologies

- Java
- Java Collections Framework
- Object-Oriented Programming

## How to Run

Compile:

```bash
javac *.java
```

Run:

```bash
java Main
```

## Project Structure

- `Pet.java` - Base Pet class
- `Dog.java` - Dog subclass
- `Cat.java` - Cat subclass
- `Bird.java` - Bird subclass
- `PetService.java` - Pet management
- `Owner.java` - Owner management
- `Appointment.java` - Appointment model
- `AppointmentService.java` - Appointment management
- `MedicalRecord.java` - Medical record model
- `MedicalRecordService.java` - Medical record management
- `ReportService.java` - System reports
- `InputValidator.java` - Input validation
- `Main.java` - Main application
